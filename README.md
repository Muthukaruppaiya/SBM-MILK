# SBM-MILK

Static React e-commerce storefront for **SBM Donkey Farm** — donkey milk, powder, urine, 0° fruits, and organic soil.

## Features

- Scroll-scrubbed farm story video (0–4s)
- Product catalogue, detail pages, cart, and order checkout (wireframe)
- Mobile menu drawer and horizontal “You may also like” scroller

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Stack

- React + Vite + TypeScript
- React Router
- Framer Motion
